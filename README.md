# Medicine Availability Network (MAN)

## Project Overview
Medicine Availability Network (MAN) is a web-based platform designed to help patients find required medicines in nearby pharmacies. The system allows users to search for medicines and check their reported availability without physically visiting multiple pharmacies.

The platform connects patients with pharmacies through a centralized system that provides medicine availability information, pharmacy details, and location-based search functionality.

## Problem Statement
Patients often face difficulties finding specific medicines in nearby pharmacies. They have to visit multiple medical stores or contact pharmacies individually to check medicine availability. This process wastes time and creates inconvenience, especially during urgent medical needs.

## Proposed Solution
Medicine Availability Network (MAN) provides an online platform where patients can search for required medicines and view their reported availability in nearby pharmacies. Registered pharmacies can manage and update their medicine inventory, while administrators verify pharmacy accounts to improve platform reliability.

## Project Objectives
- To provide an easy way to search for medicines online.
- To help patients find nearby pharmacies.
- To display reported medicine availability.
- To allow pharmacies to update their inventory.
- To provide pharmacy verification through an administrator.
- To reduce the time and effort required to find medicines.

## Key Features
1. **Medicine Search:** Search medicines by name, brand, or generic name.
2. **Location-Based Search:** Find nearby pharmacies based on location.
3. **Medicine Availability:** View reported stock availability.
4. **Inventory Management:** Allow pharmacies to update medicine stock information.
5. **Pharmacy Verification:** Verify registered pharmacies through an admin panel.
6. **Real-Time Inventory Updates:** Display updated inventory information when pharmacies submit changes.
7. **User Authentication:** Secure registration and login for different users.

- Search for required medicines.
- View medicine availability.

### 2. Pharmacy Module
- Pharmacy registration.
- Manage pharmacy profile.
- Add and update medicine inventory.
- Update medicine availability.

### 3. Admin Module
- Manage registered users.
- Verify pharmacy accounts.
- Manage medicine records.
- Monitor platform activities.

## Project Architecture
The project follows a client-server architecture. React.js is used to develop the frontend interface, while Django REST Framework handles backend operations and API requests. SQLite is used to store application data.
